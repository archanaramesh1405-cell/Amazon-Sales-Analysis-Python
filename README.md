# Amazon Sales Data Analysis Using Python

## Project Overview
This project focuses on analyzing Amazon sales data using Python to understand sales patterns and extract useful insights from the dataset.

## Objectives
- Analyze the Amazon sales dataset.
- Perform data cleaning and exploratory data analysis.
- Identify important sales trends.
- Present findings using data analysis and visualizations.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib and Seaborn (if used)

## Project File
- `amazon-sales-dataset-eda.ipynb` – Jupyter Notebook containing the analysis.

## Analysis Performed
The notebook contains the data exploration, data processing, analysis, and visualizations performed for this project.

## Conclusion
This project demonstrates the use of Python for data analysis and helps develop practical skills in data cleaning, exploratory data analysis, and visualization.
